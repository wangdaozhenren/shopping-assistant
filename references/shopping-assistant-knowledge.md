# 全网购物助手 · 领域知识模块

> 挂载知识类：① 计价口径 · ② 规格归一 · ⑤ 安全避坑 · ⑥ 平台/渠道知识

## ① 计价口径：页面价 ≠ 到手价

- **价格类型分级**：标价 / 券后价（领券） / 会员价 / 百亿补贴价 / 新人价——报告优先用无条件可见价，券后价标注领券条件。
- **批发 vs 零售**：1688 价是批发价（含税未含运费、有起批量），与京东/淘宝零售价**不可直接比**，需注明口径。
- **运费与起批量**：1688 单件价低但运费与 MOQ 可能抬高总成本；总成本 = 单价 × 数量 + 运费。
- **活动价陷阱**：大促价、限时价页面过期即恢复，报告标注"活动价截至读取时点"。

## ② 规格归一（核心，防错比）

- **单位价是唯一公平口径**：330ml×24 罐 vs 500ml×12 瓶，必须换算元/升或元/罐再比。
- **双规格标题**：标题写"12/24 罐可选"时页面价常对应最小规格——强制开卡核实，宁缺毋假。
- **不同包装形态**：罐装/瓶装/袋装/礼盒装不可直接比；整箱 vs 散装需换算单件价。
- **新旧版本**：同商品新旧包装并存，以规格参数（ml/g/数量）为准，不以包装判断同款。

## ⑤ 安全避坑

- **低价假货**：明显低于市场价 40% 以上的店铺（尤其数码、美妆、保健品）提示"疑似假货/水货，核对店铺资质"。
- **刷单刷分**：高评分低销量、评价图片雷同、好评集中在短时间——提示评价参考价值有限。
- **预付定金陷阱**："定金"不退、"订金"可退，预售前报告提示区分。
- **第三方店铺 vs 自营/旗舰店**：价格与售后差异大，报告标注店铺性质。

## ⑥ 平台/渠道知识

| 平台 | 特点 | 注意点 |
|---|---|---|
| 京东 | 自营物流快、售后稳 | 自营价 vs 第三方价可比性更好；Plus 会员价 |
| 1688 | 批发源头价 | 起批量+运费口径；商家多工厂 |
| 淘宝/天猫 | C 店 + 旗舰店混合 | C 店价格低但售后弱；天猫旗舰店保真 |
| 拼多多 | 百亿补贴/券后价常见 | 依赖登录态领券；价格口径波动大 |
| 苏宁 | 家电 3C 有优势 | 免登录可读，结构类似京东 |

- 同一商品跨平台"同款"判定用"规范化标题 + 规格键"指纹；匹配分 <60 的近似款只作参考，不冒充同款。
